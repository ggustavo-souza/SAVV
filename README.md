
# SAVV
Um website voltado para a população de Votorantim, com o intuito de registrar e monitorar denúncias referentes ao meio ambiente da cidade.

## Comandos para configurar nome e email no terminal: 
Para usar o git no terminal e no VScode, você precisar logar com sua conta no terminal 

Aqui pra registrar seu nome:
``` git config --global user.name "{seu nome no github}" ```

Aqui pra registrar seu email:
``` git config --global user.email "{o email que você usa sua conta no git}" ```
