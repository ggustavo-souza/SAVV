# SAVV - Sistema de Áreas Verdes de Votorantim

Este repositório é referente ao projeto SAVV, uma iniciativa partida dos alunos Carlos, Gustavo, Igor e Maycon da Fatec Votorantim, de um sistema projetado para atender uma necessidade tanto da população quanto da prefeitura da cidade de Votorantim.

## Conteúdo do Repositório

- **Arquivos fonte do projeto**: As pastas (/app, /services, /types, /components, /lib, /public) são referentes ao código fonte do projeto, escrito em Next.js

- **Documentação do projeto**: O arquivo `2026.2_Projeto Interdisciplinar - ES2 - rev (1).docx` é referente à documentação do projeto completa, contendo todo o planejamento do projeto junto com diagramas e capturas de tela demonstrando o projeto.

- **Arquivo fonte do Banco de Dados**: O arquivo `savvBD.sql` é referente ao banco de dados do projeto. 

## Atenção!

O projeto **necessita de um banco de dados conectado para funcionar corretamente**, devido às funcionalidades de back-end já implementadas a fim de já analisar o que estaria correto e o que necessitaria de mudanças.

## Como rodar o projeto? 

Devido a arquitetura Next.js, os passos são simples e serão listados a seguir:

1. Primeiro, deve se clonar o projeto dentro do seu dispositivo, na pasta desejada:
```
git clone "https://github.com/ggustavo-souza/SAVV.git
```
2. Após a clonagem do projeto, você deve abrir um prompt de comando (terminal), adentrar a pasta clonada, e executar o comando de **Instalação de Dependências**.
```
npm install
```
3. Com as dependências instaladas, resta apenas rodar o servidor da aplicação:
```
npm run dev
```
